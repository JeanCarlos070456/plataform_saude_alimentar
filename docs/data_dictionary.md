# Dicionário da base analítica

| Campo | Significado |
|---|---|
| record_id | Identificador técnico sem nome pessoal |
| school_code | Código interno da escola (1–7) |
| school_name | Nome padronizado da escola |
| school_inep | Código INEP |
| sex | Feminino/Masculino conforme instrumento |
| age_years | Idade em anos |
| age_group | 7–9, 10–11, 12–14 ou 15–17 anos |
| shift | Matutino/Vespertino |
| mother_education | 0–8, 9–11, ≥12 anos ou não soube informar |
| income_group | Até 1 SM, 1 a 2 SM ou >2 SM |
| race_group | Brancos, pardos/pretos ou outras raças/cores |
| insecurity_level | Sem insegurança, algum risco, risco moderado/grave |
| any_insecurity | 1 quando pelo menos uma das duas perguntas foi positiva |
| moderate_severe | 1 quando ambas as perguntas foram positivas |

O indicador é operacional e não equivale à EBIA completa.
